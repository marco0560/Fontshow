# Inventory JSON Schema

This section documents the JSON schema used by Fontshow to validate
font inventory files.

## Versions

- **1.0** – Initial informal schema (implicit)
- **1.1** – Formalized schema with structured inference and warnings

## Files

- [`font-inventory-schema.md`](font-inventory-schema.md)
- [`inventory-1.1.schema.json`](inventory-1.1.schema.json)

The schema supports both raw and enriched inventories.
