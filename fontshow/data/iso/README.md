# ISO 15924 Data Snapshot (Vendored)

This directory contains a vendored snapshot of the ISO 15924
script code registry published by the Unicode Consortium,
which acts as ISO 15924 Registration Authority.

## Source

[https://www.unicode.org/iso15924/iso15924.txt]<https://www.unicode.org/iso15924/iso15924.txt>

## Purpose

Used to deterministically map Unicode Script properties
to ISO 15924 four-letter script codes.

## Rules

- File MUST NOT be edited manually.
- Updates require replacing the upstream snapshot
  and regenerating derived tables.
